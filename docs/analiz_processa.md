# Анализ бизнес-процесса оформления заказа

## Описание предметной области

Процесс «Оформление заказа» является одним из ключевых бизнес-процессов интернет-магазина. Он связывает действия покупателя, работу информационной системы и взаимодействие с внешними сервисами оплаты.

В рамках проекта рассматривается процесс оформления заказа со стороны покупателя и информационной системы интернет-магазина:

**Выбор товара → Формирование корзины → Ввод данных покупателя → Оплата → Фиксация заказа в системе**

Операции склада и доставки не входят в границы рассматриваемого процесса, так как относятся к следующим этапам исполнения заказа.

---

## Участники процесса

| Участник | Роль в процессе |
| -------- | --------------- |
| Покупатель | Выбирает товары, формирует заказ, вводит данные и подтверждает оплату |
| Информационная система интернет-магазина | Обеспечивает работу каталога, корзины, оформление заказа, проверку данных и сохранение результатов |
| Платежная система | Выполняет обработку платежа и возвращает результат транзакции |
| База данных | Хранит информацию о товарах, корзинах и заказах |

---

## Границы процесса

### Начало процесса

Покупатель выбирает товары в каталоге интернет-магазина и добавляет их в корзину.

### Завершение процесса

После успешной оплаты заказ фиксируется в системе, а пользователю предоставляется подтверждение.

### Не входит в процесс

- сборка заказа на складе;
- передача заказа в курьерскую службу;
- доставка товара покупателю.

---

## Входные данные

| Вход | Описание |
| ---- | -------- |
| Выбранные товары | Состав корзины и количество товаров |
| Данные покупателя | Контактные данные и адрес |
| Способ оплаты | Выбранный пользователем вариант оплаты |

---

## Выходные результаты

| Выход | Описание |
| ----- | -------- |
| Оформленный заказ | Созданный заказ в информационной системе |
| Статус оплаты | Результат выполнения транзакции и подтверждение оплаты |
| Запись в базе данных | Сохранённая информация о заказе |

---

## Основные этапы процесса

1. Выбор товара и добавление в корзину.
2. Проверка наличия выбранных товаров.
3. Ввод и проверка данных покупателя.
4. Формирование заказа.
5. Проведение оплаты.
6. Подтверждение заказа и сохранение информации в системе.
